# 🏥 AI-Powered Healthcare Chatbot


### 🌟 Overview

**AI-Powered Healthcare Chatbot** is a smart conversational assistant designed to provide quick responses related to health queries.  
Built with **Streamlit** and powered by **Hugging Face’s DistilGPT-2**, it combines rule-based logic with generative AI to assist users with:

- Symptom-related questions  
- Appointment guidance  
- Medication reminders  
- General health conversations  

> ⚠️ **Disclaimer**: This chatbot is for informational purposes only and does **not** replace professional medical advice. Always consult a qualified doctor for diagnosis and treatment.

---

### ✨ Key Features

- 🤖 **AI-Powered Responses** using DistilGPT-2
- 💬 Clean & interactive Streamlit interface
- 🧠 Smart keyword detection for common healthcare topics:
  - Symptoms → Advises consulting a doctor
  - Appointment → Helps with scheduling intent
  - Medication → Encourages proper medicine intake
- ⚡ Lightweight and fast
- 📱 Fully responsive web app
